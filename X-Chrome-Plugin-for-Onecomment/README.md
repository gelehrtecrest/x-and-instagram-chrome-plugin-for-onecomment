# X-Chrome-Plugin-for-Onecomment

X Live（配信チャット）のコメントをリアルタイムに取得し、`Onecomment-Plugin-for-X-Instagram` 経由でわんコメ（OneComme）の **X用枠（`X Live コメント`）** へ送信する Chrome 拡張機能（Manifest V3）です。

## 前提条件

- わんコメに `Onecomment-Plugin-for-X-Instagram` がインストール・有効化されていること。

## インストール手順（Google Chrome）

1. Chrome のアドレスバーに `chrome://extensions/` と入力して開きます。
2. 画面右上の **「デベロッパー モード」** を ON にします。
3. **「パッケージ化されていない拡張機能を読み込む」** をクリックし、この `X-Chrome-Plugin-for-Onecomment` フォルダを選択します。
4. ツールバーにピン留めして拡張アイコンを開き、プラグイン接続が **「接続OK」** になっていることを確認します。

## 使い方

1. Chrome で X Live（配信チャットが表示されているページ、例: `https://x.com/i/broadcasts/...`）を開きます。
2. 拡張機能のポップアップを開き、スイッチが ON・現在のタブが **「チャット監視中」** であることを確認します。
3. 新規に投稿されたチャットが自動的にわんコメの `X Live コメント` 枠へ反映されます。
4. X の仕様変更でコメントが取得できなくなった場合は、**「詳細設定」** 画面の「カスタムCSSセレクタ」からセレクタを上書きできます。

## 安定して動作させるためのコツ（バックグラウンド時の注意点）

本拡張機能は別タブを開いていても動作する作りですが、Chrome の省電力機能やバックグラウンドタブの描画・タイマー制限により、コメントの反映が遅れたりタブに戻るまで一時停止したりする場合があります（特に DOM 監視モード時）。安定運用のため、以下の使い方を推奨します。

1. **X Live は「別ウィンドウ」で開き、最小化しない**
   - 同じウィンドウ内で別タブに切り替えたり、ウィンドウを最小化したりすると、Chrome が画面更新やタイマーを制限するため反映が止まりやすくなります。
   - X Live 専用の別ウィンドウで開き、**最小化せずそのウィンドウ内で X Live タブをアクティブにした状態**にしておくと（他のアプリや別ウィンドウの後ろに隠れていても）安定して動作します。
2. **「チャット監視中」を確認してから他作業へ移る**
   - 初回のチャット欄検出に画面上の要素サイズを使用しているため、配信ページを開いた直後は一度表示した状態で、ポップアップが **「チャット監視中」** になったことを確認してください。
3. **Chrome のメモリ セーバー対象外に登録する**
   - 長時間操作しないタブが Chrome に自動スリープされるとコメント取得が停止します。
   - Chrome のアドレスバーで `chrome://settings/performance` を開き、**「常にアクティブにするサイト」** に `x.com` を追加しておくとスリープを防止できます。
4. **反映されない・拡張機能を更新した直後は F5 で再読み込みする**
   - 拡張機能の再読み込み直後や、ポップアップに「要ページ再読込」と表示されている場合は、X Live のタブを **F5 で再読み込み** してください。
